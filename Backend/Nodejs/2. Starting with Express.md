### **Stage 3: Intermediate Node.js Concepts**

#### **1. Introduction to Express.js**

Express.js is a lightweight, unopinionated web framework for Node.js, designed to help developers build robust and flexible applications. With Express, you can easily create APIs, handle routing, set up middleware, and manage error handling, making it one of the most popular frameworks for Node.js.

---

##### **1.1 Installing Express.js**

To start using Express in your project, install it via NPM:

```bash
npm install express
```

Once installed, you can import and use it in your project:

```javascript
const express = require('express');
const app = express();
```

---

##### **1.2 Setting Up a Basic Express Server**

Here’s a simple Express server that responds with “Hello, Express!” when you access the root URL.

```javascript
const express = require('express');
const app = express();
const PORT = 3000;

app.get('/', (req, res) => {
  res.send('Hello, Express!');
});

app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`);
});
```

**Explanation**:
- `app.get('/', handler)`: Defines a route for GET requests to the root URL (`/`).
- `app.listen(PORT)`: Starts the server on the specified port.

---

#### **2. Routing in Express**

Routing refers to determining how an application responds to specific client requests. Express provides several HTTP methods like `GET`, `POST`, `PUT`, `DELETE`, and more, to set up routes for different endpoints.

**Example Routes**:

```javascript
app.get('/api/users', (req, res) => {
  res.send('Get a list of users');
});

app.post('/api/users', (req, res) => {
  res.send('Create a new user');
});

app.put('/api/users/:id', (req, res) => {
  res.send(`Update user with ID: ${req.params.id}`);
});

app.delete('/api/users/:id', (req, res) => {
  res.send(`Delete user with ID: ${req.params.id}`);
});
```

**Explanation**:
- **Route Parameters** (`:id` in `/api/users/:id`): Used to capture dynamic values in the URL, accessible through `req.params`.
- **Different HTTP Methods**: Define different actions for the same route, such as retrieving, creating, updating, or deleting data.

#### **3. Middleware in Express**

Middleware functions are functions that have access to the request (`req`), response (`res`), and next (`next`) objects in the application's request-response cycle. They can execute code, modify the request and response objects, end the request-response cycle, or call the next middleware function.

1. **Types of Middleware**:
   - **Application-level**: Applied globally in the app.
   - **Router-level**: Applied only to a specific router.
   - **Error-handling**: Captures errors and processes them appropriately.

2. **Using Middleware**:
   - To use a middleware globally:
     ```javascript
     app.use((req, res, next) => {
       console.log('Middleware function');
       next(); // Passes control to the next middleware or route
     });
     ```

3. **Built-in Middleware**:
   - `express.json()`: Parses incoming JSON requests.
   - `express.urlencoded({ extended: true })`: Parses URL-encoded data.

**Example**:
   ```javascript
   app.use(express.json());  // Parses incoming requests with JSON payloads

   app.post('/api/data', (req, res) => {
     console.log(req.body);  // Access parsed JSON data from the request
     res.send('Data received');
   });
   ```

---

#### **4. Error Handling in Express**

Proper error handling is essential to build reliable applications. In Express, error-handling middleware functions can capture errors and respond accordingly.

**Example Error-Handling Middleware**:
```javascript
app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).send('Something went wrong!');
});
```

- **Usage**: The error-handling middleware is added at the end of the middleware stack, capturing any errors that occur during request processing.

**Example with Route-level Error**:
```javascript
app.get('/error', (req, res, next) => {
  const err = new Error('Intentional Error');
  next(err);  // Passes the error to the error-handling middleware
});
```

#### **5. Serving Static Files**

Express makes it easy to serve static files (e.g., images, CSS, JavaScript files) using `express.static`.

**Example**:
```javascript
app.use(express.static('public'));
```

- **Explanation**: With this setup, files in the `public` directory can be accessed directly, e.g., `http://localhost:3000/image.png`.

#### **6. Creating an API with Express**

Express is commonly used to create APIs. Here’s a quick guide to setting up a simple API with endpoints for a CRUD application.

**Example**: A simple `todo` API

```javascript
const express = require('express');
const app = express();
app.use(express.json());

let todos = [
  { id: 1, task: 'Learn Express.js', completed: false }
];

// Get all todos
app.get('/api/todos', (req, res) => {
  res.json(todos);
});

// Get a specific todo
app.get('/api/todos/:id', (req, res) => {
  const todo = todos.find(t => t.id === parseInt(req.params.id));
  if (!todo) return res.status(404).send('Todo not found');
  res.json(todo);
});

// Create a new todo
app.post('/api/todos', (req, res) => {
  const newTodo = { id: todos.length + 1, task: req.body.task, completed: false };
  todos.push(newTodo);
  res.status(201).json(newTodo);
});

// Update a todo
app.put('/api/todos/:id', (req, res) => {
  const todo = todos.find(t => t.id === parseInt(req.params.id));
  if (!todo) return res.status(404).send('Todo not found');
  todo.task = req.body.task;
  todo.completed = req.body.completed;
  res.json(todo);
});

// Delete a todo
app.delete('/api/todos/:id', (req, res) => {
  const todoIndex = todos.findIndex(t => t.id === parseInt(req.params.id));
  if (todoIndex === -1) return res.status(404).send('Todo not found');
  const deletedTodo = todos.splice(todoIndex, 1);
  res.json(deletedTodo);
});

app.listen(3000, () => {
  console.log('Server is running on http://localhost:3000');
});
```

**Explanation**:
- `GET /api/todos`: Retrieves all todo items.
- `GET /api/todos/:id`: Retrieves a specific todo by ID.
- `POST /api/todos`: Creates a new todo.
- `PUT /api/todos/:id`: Updates an existing todo.
- `DELETE /api/todos/:id`: Deletes a specific todo.

**Example Usage**:
- **Create** a new todo: `POST /api/todos` with body `{ "task": "New Task" }`.
- **Retrieve** all todos: `GET /api/todos`.
- **Update** a todo by setting `completed: true`.
- **Delete** a todo by ID.
