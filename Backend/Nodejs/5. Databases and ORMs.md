### **Stage 3: Intermediate Node.js Concepts**

#### **4. Databases and ORMs**

Data storage and management are critical aspects of any web application. Node.js provides various options for interacting with databases, whether NoSQL or SQL. This section focuses on MongoDB (a NoSQL database) using Mongoose and SQL databases using Sequelize (an ORM for SQL databases).

---

##### **4.1 Introduction to Databases**

- **NoSQL vs. SQL Databases**:
  - **NoSQL Databases** (e.g., MongoDB): Use flexible schemas, are document-oriented, and are designed for scalability. They store data in JSON-like documents, making it easy to handle unstructured or semi-structured data.
  - **SQL Databases** (e.g., PostgreSQL, MySQL): Use structured schemas, with predefined tables and relationships. They are ideal for complex queries and data integrity.

---

##### **4.2 Setting Up MongoDB with Mongoose**

**MongoDB** is a popular NoSQL database. **Mongoose** is an ODM (Object Data Modeling) library for MongoDB and Node.js that provides a straightforward way to model your data.

1. **Install MongoDB and Mongoose**:

   ```bash
   npm install mongoose
   ```

2. **Connecting to MongoDB**:

   ```javascript
   const mongoose = require('mongoose');

   mongoose.connect('mongodb://localhost:27017/mydatabase', {
     useNewUrlParser: true,
     useUnifiedTopology: true,
   })
   .then(() => console.log('MongoDB connected'))
   .catch(err => console.error('MongoDB connection error:', err));
   ```

3. **Creating a Mongoose Schema**:

   ```javascript
   const userSchema = new mongoose.Schema({
     name: { type: String, required: true },
     email: { type: String, required: true, unique: true },
     age: { type: Number, min: 0 },
   });

   const User = mongoose.model('User', userSchema);
   ```

- **Explanation**: The `userSchema` defines the structure of the user documents, specifying fields, types, and validation rules.

---

##### **4.3 CRUD Operations with Mongoose**

1. **Creating a Document**:

   ```javascript
   const createUser = async () => {
     const user = new User({ name: 'Alice', email: 'alice@example.com', age: 30 });
     await user.save();
     console.log('User created:', user);
   };
   ```

2. **Reading Documents**:

   ```javascript
   const getUsers = async () => {
     const users = await User.find();
     console.log('Users:', users);
   };
   ```

3. **Updating a Document**:

   ```javascript
   const updateUser = async (userId, newAge) => {
     const user = await User.findByIdAndUpdate(userId, { age: newAge }, { new: true });
     console.log('User updated:', user);
   };
   ```

4. **Deleting a Document**:

   ```javascript
   const deleteUser = async (userId) => {
     await User.findByIdAndDelete(userId);
     console.log('User deleted');
   };
   ```

- **Example**: These functions demonstrate how to perform basic CRUD operations with Mongoose.

---

##### **4.4 Validation and Middleware in Mongoose**

Mongoose allows for data validation and middleware functions to execute logic before or after certain operations.

1. **Validation**: Can be defined within the schema using built-in validators or custom validation functions.

   ```javascript
   const userSchema = new mongoose.Schema({
     name: { type: String, required: true },
     email: { type: String, required: true, unique: true, match: /.+\@.+\..+/ }, // Regex for valid email
   });
   ```

2. **Middleware**: Can be defined for pre- and post-hooks.

   ```javascript
   userSchema.pre('save', function (next) {
     console.log('Before saving user:', this);
     next();  // Proceed to save the user
   });

   userSchema.post('save', function (doc) {
     console.log('User saved:', doc);
   });
   ```

##### **4.5 Setting Up SQL with Sequelize**

**Sequelize** is a promise-based Node.js ORM that supports multiple SQL dialects, such as PostgreSQL, MySQL, and SQLite.

1. **Install Sequelize and the Database Driver** (e.g., for PostgreSQL):

   ```bash
   npm install sequelize pg pg-hstore
   ```

2. **Setting Up Sequelize**:

   ```javascript
   const { Sequelize, DataTypes } = require('sequelize');

   const sequelize = new Sequelize('database', 'username', 'password', {
     host: 'localhost',
     dialect: 'postgres',  // or 'mysql' or 'sqlite'
   });
   ```

3. **Defining a Model**:

   ```javascript
   const User = sequelize.define('User', {
     name: {
       type: DataTypes.STRING,
       allowNull: false,
     },
     email: {
       type: DataTypes.STRING,
       allowNull: false,
       unique: true,
     },
     age: {
       type: DataTypes.INTEGER,
       validate: {
         min: 0,
       },
     },
   });
   ```

- **Explanation**: The `User` model defines the structure of the table with its fields and validation rules.

---

##### **4.6 CRUD Operations with Sequelize**

1. **Creating a Record**:

   ```javascript
   const createUser = async () => {
     const user = await User.create({ name: 'Bob', email: 'bob@example.com', age: 25 });
     console.log('User created:', user.toJSON());
   };
   ```

2. **Reading Records**:

   ```javascript
   const getUsers = async () => {
     const users = await User.findAll();
     console.log('Users:', users.map(user => user.toJSON()));
   };
   ```

3. **Updating a Record**:

   ```javascript
   const updateUser = async (userId, newAge) => {
     const user = await User.findByPk(userId);
     if (user) {
       user.age = newAge;
       await user.save();
       console.log('User updated:', user.toJSON());
     }
   };
   ```

4. **Deleting a Record**:

   ```javascript
   const deleteUser = async (userId) => {
     const result = await User.destroy({ where: { id: userId } });
     if (result) {
       console.log('User deleted');
     } else {
       console.log('User not found');
     }
   };
   ```

- **Example**: These functions illustrate how to perform CRUD operations with Sequelize.

---

##### **4.7 Associations in Sequelize**

Sequelize supports relationships between models, such as one-to-one, one-to-many, and many-to-many.

1. **Defining Associations**:

   ```javascript
   const Post = sequelize.define('Post', {
     title: DataTypes.STRING,
     content: DataTypes.TEXT,
   });

   User.hasMany(Post);  // A User can have many Posts
   Post.belongsTo(User); // A Post belongs to a User
   ```

2. **Using Associations**:

   ```javascript
   const createPostForUser = async (userId, postTitle) => {
     const user = await User.findByPk(userId);
     if (user) {
       const post = await Post.create({ title: postTitle, UserId: user.id });
       console.log('Post created:', post.toJSON());
     }
   };
   ```

---

##### **4.8 Transactions in Sequelize**

Sequelize allows you to execute multiple operations in a single transaction, ensuring data integrity.

**Example**:

```javascript
const createUserWithPost = async (userData, postData) => {
  const transaction = await sequelize.transaction();

  try {
    const user = await User.create(userData, { transaction });
    const post = await Post.create({ ...postData, UserId: user.id }, { transaction });
    
    await transaction.commit();
    console.log('User and Post created successfully:', user.toJSON(), post.toJSON());
  } catch (error) {
    await transaction.rollback();
    console.error('Transaction failed:', error);
  }
};
```

- **Explanation**: This function creates a user and a post in a single transaction. If any operation fails, it rolls back all changes, maintaining data integrity.

##### **4.9 Conclusion**

- **Choosing Between MongoDB and SQL Databases**: The choice depends on your application requirements. MongoDB is ideal for flexible, schema-less data, while SQL databases are better for structured data and complex relationships.

- **Mongoose vs. Sequelize**: Mongoose is great for document-oriented data in MongoDB, while Sequelize excels in managing relationships and transactions in SQL databases.

- **Error Handling**: Ensure proper error handling for database operations to avoid application crashes and ensure a better user experience.
