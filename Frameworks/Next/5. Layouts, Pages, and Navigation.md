## **Chapter 5: Layouts, Pages, and Navigation**

In Next.js, effective management of layouts, pages, and navigation is crucial for building scalable and user-friendly applications. This chapter will cover the implementation of layouts, the structure of pages, and navigation techniques using the App Router.

---

### **5.1 Layouts in the App Router (Persistent Layouts with `layout.js`)**

Layouts in Next.js help maintain a consistent UI structure across different pages. The `layout.js` file allows you to define persistent layouts that wrap around your page components, enabling shared UI elements such as headers, footers, or sidebars.

#### **Creating a Layout**

1. **Define a Layout Component:**

   Create a `layout.js` file in the relevant folder structure for your layout. For example:

   ```
   app/
   ├── dashboard/
   │   ├── layout.js
   │   └── page.js
   ```

2. **Implement the Layout Component:**

   In `layout.js`, you can define your layout structure:

   ```javascript
   export default function DashboardLayout({ children }) {
     return (
       <div>
         <header>
           <h1>Dashboard Header</h1>
         </header>
         <main>{children}</main>
         <footer>
           <p>Dashboard Footer</p>
         </footer>
       </div>
     );
   }
   ```

   This layout will render the header and footer around any pages within the `dashboard` route.

#### **Benefits of Persistent Layouts**

- **Shared UI Elements**: Common elements are defined once, reducing code duplication.
- **State Preservation**: Layouts help maintain component state as users navigate between pages.

---

### **5.2 Nested Layouts for Complex UI Structures**

Next.js allows the creation of nested layouts to support more complex UI structures. This is particularly useful for applications with multiple levels of navigation.

#### **Creating Nested Layouts**

1. **Define Nested Layouts:**

   You can create sub-layouts within the main layout. For example:

   ```
   app/
   ├── dashboard/
   │   ├── layout.js
   │   ├── settings/
   │   │   ├── layout.js
   │   │   └── page.js
   │   └── page.js
   ```

2. **Implement Nested Layouts:**

   In the `settings/layout.js` file, you can define a layout specific to the settings page:

   ```javascript
   export default function SettingsLayout({ children }) {
     return (
       <div>
         <h2>Settings Menu</h2>
         <div>{children}</div>
       </div>
     );
   }
   ```

   With this structure, the `SettingsLayout` will render within the `DashboardLayout`, providing a tailored UI for the settings section.

---

### **5.3 Creating and Using the `page.js` File for Each Route**

In Next.js, each route corresponds to a `page.js` file. This file is responsible for rendering the content for that specific route.

#### **Creating a Page**

1. **Define a Page Component:**

   Create a `page.js` file in the appropriate directory. For example:

   ```
   app/
   ├── dashboard/
   │   ├── page.js
   ```

2. **Implement the Page Component:**

   In `page.js`, define the content for the dashboard:

   ```javascript
   export default function DashboardPage() {
     return <h1>Welcome to the Dashboard</h1>;
   }
   ```

   This component will be rendered when users navigate to the `/dashboard` route.

#### **Automatic Routing:**

Next.js automatically handles routing based on the folder structure and the presence of `page.js` files, allowing for a straightforward and intuitive way to manage routes.

### **5.4 Implementing Linking and Navigation Using `next/link`**

Navigating between pages in a Next.js application is made simple with the `next/link` component, which enables client-side navigation.

#### **Using the `Link` Component**

1. **Import the Link Component:**

   Import `Link` from `next/link`:

   ```javascript
   import Link from 'next/link';
   ```

2. **Implement Navigation Links:**

   Use the `Link` component to create navigation links:

   ```javascript
   export default function Navigation() {
     return (
       <nav>
         <ul>
           <li>
             <Link href="/dashboard">Dashboard</Link>
           </li>
           <li>
             <Link href="/dashboard/settings">Settings</Link>
           </li>
         </ul>
       </nav>
     );
   }
   ```

   This will enable client-side transitions between the `dashboard` and `settings` pages without reloading the entire page.

#### **Benefits of `next/link`**

- **Client-Side Navigation**: Transitions are faster because only the necessary components are reloaded.
- **Prefetching**: Next.js automatically prefetches linked pages in the background, making navigation feel instant.

---

### **5.5 Programmatic Navigation with `useRouter`**

For scenarios where you need to navigate programmatically (e.g., after a form submission), you can use the `useRouter` hook.

#### **Using `useRouter` for Navigation**

1. **Import `useRouter`:**

   ```javascript
   import { useRouter } from 'next/navigation';
   ```

2. **Implement Programmatic Navigation:**

   You can navigate in response to events, such as form submissions:

   ```javascript
   export default function MyComponent() {
     const router = useRouter();

     const handleSubmit = (event) => {
       event.preventDefault();
       // Perform some action (e.g., form validation)
       router.push('/dashboard'); // Navigate to the dashboard page
     };

     return (
       <form onSubmit={handleSubmit}>
         <button type="submit">Submit</button>
       </form>
     );
   }
   ```

   This will redirect the user to the `/dashboard` page after submitting the form.
