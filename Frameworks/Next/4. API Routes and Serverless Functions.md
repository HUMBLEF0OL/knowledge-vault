## **Chapter 4: API Routes and Serverless Functions**

Next.js provides a powerful way to create APIs alongside your application through API routes. This chapter will cover how to create API routes, work with serverless functions, handle HTTP requests, and introduce Edge Functions for faster execution.

---

### **4.1 Creating API Routes Using the `app/api/` Directory**

In Next.js, you can create API endpoints by placing JavaScript or TypeScript files in the `app/api/` directory. Each file corresponds to a specific API route, allowing you to define server-side logic.

#### **Example of Creating an API Route**

1. **Creating a New API Route:**

   To create a new API endpoint, create a file in the `app/api/` directory. For example, to create an endpoint for fetching users:

   ```
   app/api/users/route.js
   ```

2. **Defining the API Route:**

   In `route.js`, export a function that handles the request:

   ```javascript
   export async function GET(request) {
     const res = await fetch('https://api.example.com/users');
     const users = await res.json();
     
     return new Response(JSON.stringify(users), {
       status: 200,
       headers: { 'Content-Type': 'application/json' },
     });
   }
   ```

   In this example, the `GET` function handles GET requests to the `/api/users` endpoint, fetching user data from an external API and returning it as a JSON response.

#### **File Structure:**

```
app/
├── api/
│   ├── users/
│   │   └── route.js
```

### **4.2 Working with Serverless Functions**

API routes in Next.js operate as serverless functions. This means that you can execute server-side code in response to HTTP requests without needing to manage a server.

#### **Example of a POST API Route:**

You can create an API endpoint that handles POST requests, for example, to create a new user:

```javascript
export async function POST(request) {
  const userData = await request.json();

  // Process user data (e.g., save to a database)
  const res = await fetch('https://api.example.com/users', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(userData),
  });

  const user = await res.json();

  return new Response(JSON.stringify(user), {
    status: 201,
    headers: { 'Content-Type': 'application/json' },
  });
}
```

In this example, the `POST` function processes incoming user data, sends it to an external API, and returns the created user in the response.

### **4.3 Handling HTTP Requests (GET, POST, etc.)**

Next.js API routes can handle various types of HTTP requests, such as GET, POST, PUT, and DELETE. You can define functions for each HTTP method as needed.

#### **Example of Handling Multiple HTTP Methods:**

```javascript
export async function handler(request) {
  if (request.method === 'GET') {
    // Handle GET request
    const res = await fetch('https://api.example.com/data');
    const data = await res.json();
    return new Response(JSON.stringify(data), { status: 200 });
  } else if (request.method === 'POST') {
    // Handle POST request
    const requestBody = await request.json();
    // Process requestBody...
    return new Response('Data received', { status: 201 });
  } else {
    return new Response('Method Not Allowed', { status: 405 });
  }
}
```

This function responds differently based on the HTTP method of the incoming request.

### **4.4 Introduction to Next.js Edge Functions for Faster Execution**

Next.js Edge Functions allow you to run your API routes closer to your users by executing them at the edge. This improves performance, especially for latency-sensitive applications.

#### **How Edge Functions Work:**

- **Deployment**: When you deploy your application, Next.js automatically deploys your API routes as Edge Functions on a global Content Delivery Network (CDN).
- **Execution**: Requests to your API routes are processed at edge locations, resulting in faster response times.

#### **Creating Edge Functions:**

To create an Edge Function, you can specify it in your API route by adding the `runtime` configuration:

```javascript
export const runtime = 'edge';

export async function GET(request) {
  const res = await fetch('https://api.example.com/data');
  const data = await res.json();
  return new Response(JSON.stringify(data), { status: 200 });
}
```

By setting `runtime` to `'edge'`, you enable your API route to run as an Edge Function.

#### **Benefits of Edge Functions:**

- Reduced latency for users by processing requests closer to their geographic location.
- Improved performance for high-traffic applications due to distributed execution.
